# Plan Tasks

Provide an exhaustive plan to address everything we have discussed. Each item should be broken down into specific task items and definition of done. 
Include a **Motivation** section at the top of the document that outlines the motivation behind the changes that the plan prescribes. This should provide 
enough background so that an audit that found this plan would understand the circumstances and decisions that led to this plan being developed.
Save this plan to a PLAN.md document in the root of this project. If a PLAN.md already exists, overwrite it.
